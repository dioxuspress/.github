# Security Policy

## Reporting a Vulnerability

We take the security of all projects under the [**DioxusPress**](https://github.com/dioxuspress) organization seriously — especially authentication, CSP/XSS sanitization, server-side rendering, and local file indexing.

**Please do not open a public GitHub issue for security vulnerabilities.**

Instead, please report vulnerabilities privately using **GitHub Private Vulnerability Reporting** on the affected repository:

1. Navigate to the affected repository's **Security** tab (for example, `https://github.com/dioxuspress/dioxuspress/security/advisories/new`).
2. Click **Report a vulnerability** and provide:
   - Affected repository and version/commit SHA
   - Reproduction steps or proof of concept
   - Potential impact and any suggested mitigation

## Response Expectations

- **Acknowledgement**: Within 72 hours of submission
- **Triage & Fix**: Critical and high-severity issues are prioritized for coordinated patch releases and advisories
- **Credit**: Reporters are credited in the published security advisory unless anonymity is requested

## Supported Versions

Security fixes are applied to the latest minor release and the `main` branch of each repository.
